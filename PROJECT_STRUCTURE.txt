Infrastructure (Docker)
-----------------------
Docker Compose includes:
- PostgreSQL (Auth DB)           Port 5432
- PostgreSQL (Orders DB)         Port 5433
- PostgreSQL (Payments DB)       Port 5434
- PostgreSQL (Cooks DB)          Port 5435
- Redis                          Port 6379
- Meilisearch                    Port 7700

Quick Commands
--------------
npm install                      Install dependencies
npm run docker:up                Start infrastructure
npm start                        Start API Gateway
npm run dev:auth                 Start Auth Service
node scripts/start-all-services.js   Start all services
node scripts/smoke-test.js       Test all services
npm run docker:logs              View Docker logs
npm run docker:down              Stop infrastructure
